# Strings

Connect in transparency... black and white.

## Status

Route-plumbing batch. All 62 page routes + catch-all 404 wired in Next.js 14
App Router. Each route renders a placeholder stating its screen ID. No backend,
database, auth, E2EE, WebRTC, messaging or persistence is implemented yet.

## Stack (current batch)
- Node.js 22 LTS
- Next.js 14 App Router
- React 18 + TypeScript
- Plain CSS with design tokens (src/app/globals.css)

## Run
    npm install
    npm run dev

Then open http://localhost:3000

    npm run typecheck
    npm run build
